# Подключение Python к уже имеющемуся фронтенду (не перезаписывая работу Кристины)

1. `frontend/index.html` должен продолжать загружать `styles.css` и `app.js`.
2. **После** `<script src="./app.js" defer></script>` добавьте:

```html
<script src="./backend_sync.js" defer></script>
```

3. Скопируйте `frontend/backend_sync.js` из этого пакета рядом с `app.js`.
4. Запускайте `python -m backend.server` из корня репозитория, а сайт открывайте по адресу `http://127.0.0.1:8765/`.
5. Увидите **«Python API · локальная демо-модель»**. В этом режиме кнопка `Симуляция` вызывает `POST /api/v1/simulate`.

**Важно:** обычное открытие `index.html`/Live Server оставляет встроенный JS-расчёт. Это резервный режим, не серверный.

Рядом есть полный архив с автоматически подключённым `backend_sync.js` для проверки на чистой копии проекта. Его содержимое **не нужно** механически перезаписывать поверх ваших новых изменений в VS Code.
